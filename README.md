# 🧩 Prácticas de Programación Orientada a Objetos

Aplicación desarrollada para practicar los principales conceptos de **Programación Orientada a Objetos en Java** mediante 10 ejercicios.

### 📚 Ejercicios

* 🔷 Clases y métodos abstractos
* 🔒 Modificador `final`
* 🔌 Interfaces
* 🦆 Implementación de múltiples interfaces
* 👨‍💼 Herencia y clases abstractas
* 🚫 Restricción de herencia con `final`
* 🏦 Interfaces en cuentas bancarias
* 🐶 Herencia y UML
* 🚗 Herencia y polimorfismo
* 💾 Interfaces para dispositivos USB

### 🧠 Conceptos

**Abstracción · Herencia · Polimorfismo · Interfaces · Encapsulamiento · `final` · UML**
